# Дизайн-скріншоти

Усі знімки зроблені з **вигаданими даними** (префікс «ТЕСТ_»): запити до бази підміняються в браузері, реальних даних у кадрі немає.

- `screenshots/before/` — до змін (`d-` десктоп 1440, `m-` телефон 390)
- `screenshots/after/` — після (світла тема)
- `screenshots/after-dark/` — після (темна тема)

Джерело стилю: `docs/style.md`.
