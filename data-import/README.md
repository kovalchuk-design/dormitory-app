# Наповнення бази даних (data-import)

Гілка для роботи з початковим завантаженням даних: учні, кімнати, архів документів, івенти.

## Правила
- **Реальні персональні дані в git не потрапляють.** Папки `data-import/input/` і `data-import/output/` ігноруються (див. `.gitignore`). У репозиторії лише скрипти, шаблони та вигадані зразки в `data-import/samples/`.
- Скрипти працюють через Supabase з правами адміністратора (вхід під обліковим записом, без `service_role` у коді).
- Кожен імпорт спершу запускається в режимі `--dry-run` (звіт без запису), потім із записом; уся робота в транзакції або з можливістю відкоту.

## Що планується імпортувати
1. Кімнати: номер, поверх, місткість.
2. Учні та анкети: ПІБ, клас, дата народження, контакти, батьки, група, професія тощо (CSV/XLSX).
3. Поточне розселення учнів по кімнатах.
4. Архів документів (Word/PDF): файл + категорія, тема, рік, автор, теги.
5. Описи івентів і журнал відвідування (після затвердження структури).

## Структура
- `input/` — вихідні файли (не в git)
- `output/` — звіти імпорту (не в git)
- `samples/` — вигадані зразки формату
